# Operit2 前台语音插件验收记录

日期：2026-10-17 至 2026-10-18。插件：`com.skymoni.voice_calls`，版本 `0.1.0`，ToolPkg API `2.0.0`。

## 实现

`operit2-plugin/` 独立安装，无需重写主应用。聊天输入菜单新增「语音通话」；宿主通用窗口承载本地 HTML 和原生挂断按钮。当前宿主接口不提供全屏通话页或系统来电界面。

通话状态由 Compose 窗口的 `useRef` 持有。不能依赖 main IPC 调用之间的模块级 Map：此 SDK 的 main engine 使用计数租约，单次调用结束可能销毁引擎。服务直接运行在持有窗口租约的 UI runtime，聊天请求中的 `runtime: "main"` 仍指原聊天流水线。窗口关闭前同步使状态失效并发起清理。

收音使用安全上下文 WebView 的 `getUserMedia` 和 Web Audio；前端生成真实 PCM16 WAV 后调用 `Tools.Stt.transcribe`。生产路径每个新轮次只调用一次 `Tools.Chat.sendMessage`，检查其真实 outcome 与完整回复后显示字幕、调用 `Tools.Tts.synthesize`，不在失败后自动补发。设备测试曾出现观察器已显示全文、原聊天已持久化而结束确认失败，首版因此不启用逐字生成字幕；可注入的流快照解析另有协议测试，不视为生产能力。

编码音频经过 `decodeAudioData` 再播放，AudioContext 在用户点击时、任何异步配置请求前启动。没有依赖未实现的 Java DEX 加载，也没有依赖宿主尚未应用的 `mediaPlaybackRequiresUserGesture` 属性。

保留原聊天的角色、记忆、模型、工具和权限处理，使用 CHAT 提示词模式。单角色会话；群聊不擅自选择成员。声音为打开通话时锁定的全局配置或手动配置，不声称自动读取角色私有声音。

## Android 验证环境

现有星伴 Operit2 0.4.0 APK，包名 `com.skymoni.starcompanion.operit`，Android API 36 模拟器。直接安装 ToolPkg，没有重建 APK、安装第二个语音 Android 客户端或下载新的 SDK／语音模型。

验证使用仅本机回环的模拟模型服务和测试数据，不使用真实账号、云端密钥或私人录音。模拟回复和测试音只用于验证接口与播放流程，不表示云端模型或真人语音体验已经验收。

已确认插件可导入启用、当前聊天菜单出现入口、本地 WebView 加载且桥接能读取指定聊天。网页运行时检测显示安全上下文为是、麦克风接口可用。Android `RECORD_AUDIO` 未授权，实际收音返回无法启动音源；没有自动授予权限，页面对此提供中文配置指引。

候选 5 已验证键盘输入 → 原会话真实提交及持久化 → 完整回复字幕 → 系统 TTS WAV 合成 → Web Audio 输出 → 自动回到键盘等待状态，无页面错误。系统设置只读确认全局声音为 `SYSTEM_TTS`／系统默认音色／WAV，没有新增 TTS 配置、云账号或密钥。Android 音频服务显示本应用的媒体播放器 started，挂断后 stopped → released。模拟器以无音频设备模式运行，未录制或试听系统输出，因此只确认合成、解码、播放状态和释放链路，不声称已人工验收音质。

另一次新轮次在页面实际显示「正在回复…」后点击原生挂断按钮，窗口立即返回原聊天，音频播放器随后 stopped／released，没有继续保持活跃。该轮原聊天仍保存了完整回复，说明取消与完成可能竞态；已验证本地关闭和取消调用路径，未证明远端模型必然停止。宿主自带「关闭」按钮也已验证返回，窗口销毁前的同步清理有对应行为测试。
